# MeaningInMusicEducation

Website for Meaning in Music, a student-run nonprofit offering free one-on-one music lessons, taught by high school musicians in the Bay Area.

- Static HTML/CSS/JS pages, with a small PHP API (`site.php`, `instruments.php`) for the admin editor and instrument listings.
- Editable site text lives in `site-content.json`.
- To run the admin page on a server, copy `config.example.php` to `config.php` and set a password. `config.php` is git-ignored.

Everything lives in one folder; there are no subfolders.
